# Security policy

## Reporting a vulnerability in this project

Use GitHub's private vulnerability reporting: the **Security** tab → **Report a vulnerability**. Please don't open a public issue. Examples:
- the scanner or scripts executing untrusted input;
- the validator letting secrets or personal data through.

Expect an acknowledgement within 7 days.

## Findings about other projects

If you use this skill on someone else's codebase and it reports a security issue, verify it first. Then report it privately to that project's maintainers through their own security policy. Don't post unverified findings about third-party software in this repository's issues.
